DevToolkit puts the most useful developer utilities in one fast, offline-first Android app.

Format JSON, YAML, and XML. Test regex patterns. Compare text blocks. Build text transform pipelines. Encode and decode Base64. Parse URLs and intent URIs. Generate hashes and HMACs. Decode JWTs. Convert epoch timestamps. Explore colours and contrast ratios. Generate UUIDs, ULIDs, and Nano IDs. Create quick mock data on the go.

Why developers choose DevToolkit:

- Works offline
- No ads
- No analytics
- No network permission
- Share text directly into tools
- Clipboard-aware workflows
- Home screen widgets for quick actions
- Local history and saved tool state

Included tools:

- JSON / YAML / XML formatter
- Regex tester
- Diff / compare
- Text transform pipeline
- Base64 encoder / decoder
- URL encoder / decoder
- Hash generator
- JWT decoder
- Epoch converter
- Colour picker
- UUID / ULID / Nano ID generator
- Mock data generator
